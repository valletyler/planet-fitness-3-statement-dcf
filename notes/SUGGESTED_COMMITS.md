# Suggested Git Commit Progression

Use descriptive commits as the model develops so the repository demonstrates the build process.

1. `Add historical financial statements and model structure`
2. `Add historical operating drivers and forecast assumptions`
3. `Build working capital schedule`
4. `Build PP&E and depreciation schedule`
5. `Build debt and interest schedule`
6. `Integrate five-year income statement forecast`
7. `Integrate cash flow statement and balance sheet`
8. `Add automated balance check`
9. `Add DCF valuation and WACC`
10. `Add sensitivity tables and scenario analysis`
11. `Add executive summary and final model outputs`
